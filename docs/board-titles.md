# Названия досок

Любой обладатель ссылки может переименовать доску. Название хранится в PostgreSQL
и не изменяет ID, ссылку, HTML/CSS и `revision` кода. Миграция `003_board_title.sql`
добавляет существующим доскам пустое название и `title_revision = 0`;
интерфейс показывает «Доска» и первые восемь знаков ID.

Название очищается от пробелов по краям по Unicode White_Space, содержит не более
100 кодовых точек Unicode и не содержит управляющих знаков. Это кодовые точки,
а не байты и не визуальные графемы: составное emoji может занимать несколько знаков.
Пустой ввод сбрасывает название к fallback. Вывод выполняется через `textContent`.

`PATCH /api/boards/{id}/title` принимает один JSON-объект до 4 KiB:

```json
{"title":"Урок: HTML и CSS","base_title_revision":0}
```

Ответ 200 содержит доску с увеличенной `title_revision`; 409 — актуальную доску,
если название уже изменили. Повторное сохранение после конфликта — явное решение
перезаписать текущее название. Кнопка «Отменить» принимает последнее известное.
HTML/CSS и `updated_at` текста этот запрос не изменяет. Название не проходит через
`DocumentSync`, поэтому черновик кода и его конфликты сохраняются. Потерянный ответ
не считается успехом; повторный запрос с прежней версией может подтвердить уже
записанное название по совпадающему текущему значению. Поле сохраняется в памяти
до повторной попытки; несохранённое название не восстанавливается после перезагрузки.

Другие открытые редакторы получают название при очередном чтении доски: reconnect,
возврат к вкладке или существующий WebSocket resync (обычно до 30 секунд при
работающем соединении). Отдельные события изменения названия не публикуются;
переименование не выдаётся за новую версию кода. Обычное сохранение кода также
может принести актуальное название в событии доски.

## Недавние доски

Список остаётся локальным, не запрашивает глобальный каталог и не обходит доски
по сети для обновления названий. В существующей записи
`localStorage["collablearn:recent:v1"]` теперь допускается необязательное `title`;
старые записи без него продолжают работать. Список содержит максимум 20 ссылок,
время открытия и последнее известное название, без кода досок. Название обновляется
при открытии/чтении этой доски или подтверждении её переименования, не меняя порядок
и время открытия. На главной оно может быть устаревшим до следующего открытия.
Очистка списка удаляет локальные названия вместе со ссылками. Ошибка localStorage
не мешает открывать и переименовывать доску.
